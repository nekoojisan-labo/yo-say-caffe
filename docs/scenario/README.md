# シナリオ設計ドキュメント

このディレクトリは、妖精カフェ物語のシナリオ設計を管理する正本候補です。

本作は **経営シミュレーション + 恋愛シミュレーション** のため、小説のような一本道の章立てではなく、以下を分けて管理します。

- メインストーリー
- 経営イベント
- 恋愛キャラクター別ルート
- 危機イベント / Bad End
- フラグ・発生条件
- イベント本文の文体・口調

## ファイル構成

| ファイル | 役割 |
|---|---|
| `01_world_and_theme.md` | 世界観、作品テーマ、物語の核 |
| `02_game_flow_30day.md` | 30日プロトタイプの全体進行 |
| `03_character_routes.md` | キャラクター別ルート設計 |
| `04_event_matrix.md` | イベント一覧、発生条件、効果 |
| `05_flags_and_conditions.md` | フラグ・パラメータ管理 |
| `06_writing_style_guide.md` | 文体、会話、イベント本文の方針 |
| `07_generation_prompt.md` | AIでシナリオ設計・本文化するときのプロンプト |

## 正本方針

現時点のシナリオ実装は `src/game/scenarios/` 配下を正本候補とします。

`src/game/scenario.ts` は旧版または試作版の可能性があるため、今後の整理対象です。

## 設計の前提

まずは完成可能性を優先し、初期版は30日プロトタイプとして設計します。

- メイン危機: ゼフィロスによる悪徳金融・妨害
- 救済キャラ: ローザ
- 恋愛ルート: シオン、ルシアを優先
- 経営軸: 資金、評判、幻装レベル
- エンディング: Bad / Normal / Shion / Lucia / True

## 運用ルール

1. 先に `04_event_matrix.md` でイベントの位置と条件を決める。
2. 次に `05_flags_and_conditions.md` でフラグ名を確定する。
3. その後、イベント本文を作成する。
4. 実装前に、到達不能イベント・重複フラグ・同日イベント渋滞を確認する。
