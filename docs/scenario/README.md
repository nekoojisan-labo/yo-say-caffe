# シナリオ設計ドキュメント

このディレクトリは、妖精カフェ物語のシナリオ設計を管理する正本です。

本作は **経営シミュレーション + 恋愛シミュレーション** のため、小説のような一本道の章立てではなく、以下を分けて管理します。

- メインストーリー
- 経営イベント
- 恋愛キャラクター別ルート
- 危機イベント / Bad End
- フラグ・発生条件
- イベント本文の文体・口調

## ファイル構成

| ファイル | 役割 |
|---|---|
| `01_world_and_theme.md` | 世界観、作品テーマ、物語の核 |
| `02_game_flow_30day.md` | 30日プロトタイプの全体進行 |
| `03_character_routes.md` | キャラクター別ルート設計 |
| `04_event_matrix.md` | イベント一覧、発生条件、効果 |
| `05_flags_and_conditions.md` | フラグ・パラメータ管理 |
| `06_writing_style_guide.md` | 文体、会話、イベント本文の方針 |
| `07_generation_prompt.md` | AIでシナリオ設計・本文化するときのプロンプト |
| `08_scenario_creation_workflow.md` | 新方針で本文シナリオを作る手順 |
| `09_event_authoring_template.md` | 各イベントを書くための共通テンプレート |

## 正本方針

このディレクトリの設計方針を、今後のシナリオ制作の正本とします。

旧版・試作版のシナリオ内容は参照しません。

`src/game/scenario.ts` に既存の旧シナリオが残っていても、新規制作では内容・章立て・展開を引き継がず、必要になった段階で整理または削除対象として扱います。

実装時のシナリオ格納先は、原則として `src/game/scenarios/` 配下に統一します。

## 設計の前提

まずは完成可能性を優先し、初期版は30日プロトタイプとして設計します。

- メイン危機: ゼフィロスによる悪徳金融・妨害
- 救済キャラ: ローザ
- 恋愛ルート: シオン、ルシアを優先
- 経営軸: 資金、評判、幻装レベル
- エンディング: Bad / Normal / Shion / Lucia / True

## 運用ルール

1. 先に `04_event_matrix.md` でイベントの位置と条件を決める。
2. 次に `05_flags_and_conditions.md` でフラグ名を確定する。
3. `08_scenario_creation_workflow.md` に沿ってイベント単位で本文を作成する。
4. `09_event_authoring_template.md` を使って、各イベントの目的・条件・本文・効果を揃える。
5. 実装前に、到達不能イベント・重複フラグ・同日イベント渋滞を確認する。
