# 06 シナリオ文体ガイド

## 目的

イベント本文、会話、選択肢、ナレーションの品質と統一感を保つ。

本作は経営シミュレーション + 恋愛シミュレーションなので、文章は読み物としての魅力だけでなく、ゲームテンポも重視する。

## 基本トーン

- やさしい
- あたたかい
- 少しコミカル
- ファンタジー感がある
- 恋愛では甘さと余韻を出す
- 危機では緊張感を出すが、重くしすぎない

## イベント本文の長さ

1イベントは短く区切る。

| 要素 | 目安 |
|---|---:|
| ナレーション | 1〜3個 |
| 会話 | 5〜15個 |
| 選択肢 | 0〜1個 |
| 分岐数 | 最大3 |
| 所要時間 | 1〜3分 |

## ナレーション方針

ナレーションは説明しすぎない。

悪い例:

> シオンは千年以上森を守ってきた存在であり、祖母と過去に深い関係があり、そのため主人公に対して複雑な感情を抱いていた。

良い例:

> シオンの横顔には、長い時間をひとりで歩いてきた者だけが持つ静けさがあった。

## 会話方針

セリフはキャラの役割と感情で差をつける。

### 主人公

- 素直
- 少し不安がある
- 経営を通して成長する
- 受け身すぎない

例:

> 祖母の店だから守りたいんです。でも、私だけではまだ足りない。だから、教えてください。

### シオン

- 静か
- 古風すぎない
- 少し厳しい
- 本音を隠す
- 主人公への優しさは行動に出る

例:

> 無理をするな。店は、一日で強くなるものではない。

### ルシア

- 王子らしい余裕
- 上品
- ときどき寂しさが出る
- 主人公の店では素に戻る

例:

> 王宮の菓子より、君の焼き菓子の方が落ち着く。……不思議だね。

### ローザ

- 豪快
- 姐御肌
- 面倒見がいい
- 口調は強いが優しい
- コメディと救済の両方を担う

例:

> 泣くのは後！ まず仕入れ先を押さえるわよ！ あんたの店、潰させないからね！

### ゼフィロス

- 丁寧
- 胡散臭い
- 最初は親切そう
- 言葉の端に支配欲がある
- 怒っても品のある嫌味を言う

例:

> いえいえ、これは善意です。困っている方に手を差し伸べるのは、商人として当然でしょう？

## 選択肢の書き方

選択肢は、プレイヤーの価値観を反映するものにする。

避ける:

- 正解が露骨すぎる
- ただの好感度最大化問題
- どれを選んでも同じ

良い選択肢:

- 優しさ
- 現実的判断
- 勇気
- 保留
- 経営判断

例:

| 選択肢 | 意味 |
|---|---|
| まず帳簿を確認します | 現実的判断 |
| みんなに相談します | 協力重視 |
| それでも借りません | 信念 |

## 経営イベントの書き方

経営イベントでは、数値変化と感情変化をつなげる。

悪い例:

> 売上が上がった。評判が5上がった。

良い例:

> いつもは空いている午後の席が、今日は最後まで埋まっていた。帰り際、獣人の親子が「また来るね」と手を振ってくれた。

この後に `reputation +5` を付ける。

## 恋愛イベントの書き方

恋愛イベントは、店や経営と関係する場面から始める。

例:

- 閉店後に手伝ってくれる
- 新メニューを一緒に考える
- 評判が落ちた時に励ます
- 王族客への対応を助ける
- 森の異変を知らせに来る

恋愛だけが独立すると、経営ゲームから浮く。

## 危機イベントの書き方

ゼフィロス関連は、いきなり悪を出しすぎない。

段階を踏む。

1. 親切そうに接近
2. 困りごとを見抜く
3. 甘い条件を出す
4. 断ると圧をかける
5. 裏で妨害する
6. 証拠によって崩れる

## AIっぽさを避けるチェック

- 説明が長すぎないか
- キャラが全員同じ口調になっていないか
- 感情を直接説明しすぎていないか
- 重要な設定を一度に出しすぎていないか
- 会話が「情報交換」だけになっていないか
- 主人公が毎回「えっ」「そんな」だけになっていないか
- 選択肢に意味があるか

## イベント完成チェックリスト

- [ ] 発生条件が明確
- [ ] 完了フラグがある
- [ ] 選択肢の効果が明確
- [ ] 次イベントIDがつながっている
- [ ] キャラの口調が合っている
- [ ] 経営・恋愛・メインのどれに属するか分かる
- [ ] 長すぎない
- [ ] 1つのイベントで設定を詰め込みすぎていない
